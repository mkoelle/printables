# 3D-printed top hat with hidden electronics cage

A parametric top hat for a 220 x 220 mm bed, printed in PLA. It hides a mounting
cage for storage and IoT devices above the wearer's head, invisible from
outside. Everything is generated by Python scripts run inside FreeCAD 1.1.

## Parts

| Part | Model | STL | Notes |
|------|-------|-----|-------|
| Crown | `TopHat.FCStd` | `stl/tophat_crown.stl` | Prints upside down, turned 45 deg. Has snap groove, rib slots and wedge lip inside |
| Brim (4 quarters) | `TopHat.FCStd` | `stl/tophat_brimq1..4.stl` | Dovetail seams, glued. Inner collar takes the crown. Sides curl up |
| Hatband | `TopHat.FCStd` | `stl/tophat_hatband.stl` | Slides on from the crown's bottom end before the crown meets the brim |
| Cage | `CageFingers.FCStd` | `stl/tophat_cage_fingers.stl` | Bottom ring + 6 spring fingers, each with a toothed T-rail |
| Rail sliders | `rail.py` | (in rail tests) | Click along rails in 2.4 mm steps; device holders will snap onto them |

Assembly: glue brim quarters; slide hatband on; squeeze the cage finger tips
and push the cage up through the crown's bottom opening; snap the crown onto
the brim collar. The crown's wedge lip then presses the finger tips to the
wall.

## Files

| File | Role |
|------|------|
| `tophat_param.py` | Builds `TopHat` (crown, brim, hatband, lip) from the `Params` spreadsheet. Parameter defaults live here |
| `cage.py` | Builds `CageFingers` from TopHat's Params; rail count, finger width, head dome clearance |
| `rail.py` | Shared rail and slider geometry (imported by `cage.py` and `test_kit.py`) |
| `export_stl.py` | Exports hat parts, oriented for printing |
| `test_kit.py` | Builds the test models: `TopHatFitTests` (head fit), `FixtureTests` (joints), `RailTests` |
| `build_all.py` | Runs everything above in order |
| `TESTING.md` | What each test print checks and which parameter to change |
| `stl/round1/` | Copy of the first test prints (head fit, tolerance, rail) |

## Parameters

`Params` spreadsheet in `TopHat.FCStd`, three sections:

- **Main**: `HeadCirc`, `Oval`, `CrownH`, `Flare`, `BrimW`, `Curl`, `Wall`, `Clr`.
- **Advanced**: formulas from Main, overridable (brim, collar, snap, ribs,
  dovetails, `HeadClear`, `HeadGap`, cage and lip sizes).
- **Derived**: computed geometry, do not edit.

`tophat_param.py` rebuilds the document from its own defaults, so put lasting
changes there (or edit the spreadsheet and run only `cage.py`, `export_stl.py`
and `test_kit.py`).

## Design decisions

- **PLA for every part.** Flexures (slider tongues, cage fingers) are sized to
  stay under about 1% bending strain.
- **Nothing visible outside.** No holes, seams or ports on the crown; all
  cage features are internal. The crown prints top-down so internal features
  on its top never show.
- **Cage loads from below.** The crown flares outward (`Flare`), so its
  bottom opening is its narrowest point. Spring fingers squeeze in 6 mm to
  pass it, then spring out flush to the wall.
- **Rejected cage designs:** straight-sided cage (did not hug the flared wall),
  two-half cage with lap seams (heavier, more parts; dropped for the fingers).
- **6 rails**, evenly spaced, starting front and back. Rails stop `HeadGap`
  above a dome model of the head, so they run lower at the sides than the top
  of the head (`HeadClear`).
- **Wedge lip** under the crown top: lead-in taper then a press band that
  squeezes finger tips `LipPress` against the wall (anti-rattle).
