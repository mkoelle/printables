# printables

Personal 3D-printable models. One folder per project; each is self-contained
with its own scripts, FreeCAD models (committed, or generated by its build
tasks), STLs and docs. `tools/` holds shared tooling, such as the script
that runs a project's build inside FreeCAD.

| Project | Description | Status |
|---------|-------------|--------|
| [tophat](tophat/) | Parametric top hat with a hidden cage for storage and IoT devices | Test prints (seam key and crown joint done; cage lip next, then the full hat) |

## Getting started

### Just printing

Every project's print-ready, bed-oriented STLs are committed in `<project>/stl/`
(tophat: `stl/parts/` for the hat, `stl/tests/` for test prints).
Slice them in PLA; you don't need FreeCAD. Each project's `README.md` lists
the parts, and `TESTING.md` lists the test prints to make first.

### Changing a model

You need:

- **macOS** (scripts use a macOS system font for engraved text).
- **FreeCAD 1.1** from [freecad.org](https://www.freecad.org/downloads.php).
- **git**, and **[uv](https://docs.astral.sh/uv/)**: it provides `uvx`, which
  runs the FreeCAD MCP server for Claude Code.
- **[mise](https://mise.jdx.dev/)** to run the build tasks, and `python3`
  (macOS's own is fine).
- **[Claude Code](https://docs.anthropic.com/en/docs/claude-code)**, if you
  want Claude to edit and rebuild models.

Setup, once:

1. Clone the repo anywhere; scripts find their files from their own path.
   Then trust its mise config files:
   ```sh
   git clone https://github.com/mkoelle/printables
   cd printables && mise trust mise.toml && mise trust tophat/mise.toml
   ```
2. Install the FreeCAD MCP addon
   ([neka-nat/freecad-mcp](https://github.com/neka-nat/freecad-mcp)) by
   copying its `addon/FreeCADMCP` folder into FreeCAD's addon directory, then
   restart FreeCAD:
   ```sh
   git clone https://github.com/neka-nat/freecad-mcp.git /tmp/freecad-mcp
   cp -R /tmp/freecad-mcp/addon/FreeCADMCP "$HOME/Library/Application Support/FreeCAD/v1-1/Mod/"
   ```
3. In FreeCAD, switch to the **MCP Addon** workbench and turn on
   **FreeCAD MCP > Auto-Start Server**. From then on, the RPC server, which
   listens on `localhost:9875`, starts with FreeCAD.
4. Register the MCP server with Claude Code:
   ```sh
   claude mcp add --scope user freecad -- uvx freecad-mcp
   ```

To build a project, open FreeCAD (with the RPC server running) and run its
mise tasks from the project folder:

```sh
cd tophat
mise run build          # every step whose inputs changed; all of them after a clone
mise run -f --skip-deps tests   # only this step, even if up to date
mise tasks              # list the steps
```

Each task runs one script inside FreeCAD through `tools/fc.py`, which waits
its turn if another build is running. Without mise, run a project's
`models/build_all.py` from FreeCAD's Python console
(**View > Panels > Python console**), setting `__file__` so it can find its
files:

```python
p = "/path/to/printables/tophat/models/build_all.py"; exec(open(p).read(), {"__file__": p})
```

Each project's `CLAUDE.md` gives the build steps and the checks to read in the
output. Where a project's models are not committed (tophat), build once after
cloning to create them.

### Before working with Claude

1. **Open FreeCAD first** and check that the RPC server is running. With
   auto-start on, the Report view shows `[MCP] Auto-start: ...`. If not, click
   **Start RPC Server** in the MCP Addon workbench. Claude cannot build or
   check anything without it.
2. **Start Claude Code at the repo root**, so it reads the root `CLAUDE.md`:
   ```sh
   cd printables && claude
   ```
3. **Check the connection.** Run `/mcp` in Claude Code; `freecad` should show
   as connected. If FreeCAD was started after Claude Code, reconnect it from
   `/mcp`.
4. **Watching changes.** The scripts open their models in FreeCAD as they
   build, so you see each result in the 3D view. Models saved by a script
   replace the file on disk. If you had that file open, close and reopen it
   (or **File > Revert**).
5. **Long builds.** A full build takes about 10 minutes. Claude runs it in
   the background through mise. If you start one yourself while Claude's is
   running, `fc.py` makes it wait its turn.

## Conventions

- **CAD:** FreeCAD 1.1, driven by Python scripts (parametric where possible).
  Scripts are the source of truth; `.FCStd` models and STLs are generated from
  them. A project may leave its models out of git (tophat does): build it
  after cloning.
- **Printer:** 220 x 220 mm bed, PLA unless a project says otherwise.
- **Project layout:**
  - `README.md`: what it is, files, decisions, status
  - `CLAUDE.md`: how to build and check it (for coding agents)
  - `TESTING.md`: test prints and how to tune from them (if any)
  - `mise.toml`: build tasks, one per script
  - `models/`: scripts to run, one per model or build step
  - `lib/`: code the scripts import (never imported by another project)
  - `build/`: generated `.FCStd` models, if they are not committed
  - `stl/`: print-ready STLs, already oriented for the bed (`parts/` and
    `tests/` when there are test prints)
- STLs are committed so prints don't need FreeCAD. G-code and slicer output
  are not committed.
